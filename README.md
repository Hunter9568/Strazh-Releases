# Страж — официальные релизы

Здесь публикуются только официальные установочные файлы macOS-приложения
«Страж». Исходный код, ключи лицензирования и данные покупателей в этом
репозитории не хранятся.

## Установка

1. Скачайте DMG из раздела Releases.
2. Откройте образ и перенесите «Страж» в папку «Программы».
3. При первом запуске macOS может заблокировать приложение, потому что текущая
   версия распространяется без платного Apple Developer ID.
4. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите
   «Всё равно открыть» рядом с сообщением о «Страже».
5. Активируйте приложение индивидуальным кодом продавца.

Не отключайте Gatekeeper и не выполняйте команды `xattr` из интернета.

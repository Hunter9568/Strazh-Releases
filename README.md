# Страж

Локальный голосовой AI-помощник для macOS, который умеет разговаривать,
управлять компьютером, выполнять пользовательские сценарии и работать с
локальными или облачными моделями.

> Официальный репозиторий установочных файлов. Исходный код, приватные ключи
> лицензирования и данные покупателей здесь не публикуются.

## Возможности

| | Возможность | Что умеет «Страж» |
|---|---|---|
| 🎙️ | **Голос** | Локальное распознавание речи Whisper, активация кодовой фразой и русская озвучка |
| 🧠 | **Локальный AI** | Работа моделей LiteRT и llama.cpp непосредственно на Mac без обязательной передачи диалогов во внешний сервис |
| ☁️ | **Облачный AI** | Подключение OpenAI-совместимых API, OpenRouter, Anthropic, Ollama и собственного сервера |
| 💬 | **Чат** | История диалогов, память, вложения, персонализация и потоковая генерация ответов |
| 🖥️ | **Управление macOS** | Запуск приложений, открытие сайтов, ввод текста, громкость, музыка и таймеры |
| ⚡ | **Свои команды** | Многошаговые сценарии со своими голосовыми фразами и вариантами распознавания |
| 👁️ | **Визуальные сценарии** | Ожидание нужного приложения и работа с заранее выбранными элементами интерфейса |
| 🌐 | **Интернет** | Открытие URL и безопасный поиск в интернете из голосовых команд и AI-чата |
| 📚 | **Библиотека** | Локальное хранение документов и веб-материалов для использования в качестве контекста |
| 📁 | **Проекты** | Объединение чатов, инструкций и материалов в отдельные рабочие пространства |
| ✈️ | **Telegram** | Подготовка сообщений и удалённые голосовые команды при включённой интеграции |
| 🎨 | **Персонализация** | Темы, фон, голос, образ помощника, экранный питомец и режим стримера |
| 🛡️ | **Безопасность** | Проверка допустимых действий и подтверждение чувствительных операций пользователем |
| 🔑 | **Лицензия** | Индивидуальная активация на одном Mac, хранение данных в Связке ключей и защита Secure Enclave при наличии |
| 🔄 | **Обновления** | Проверка подлинности подписанного манифеста перед предложением новой версии |

## Системные требования

| Компонент | Требование |
|---|---|
| Компьютер | Mac с Apple Silicon: M1, M2, M3, M4 и новее |
| macOS | 14 или новее |
| Место на диске | Не менее 2 ГБ; больше при установке локальных AI-моделей |
| Разрешения | Микрофон; Универсальный доступ — только для управления интерфейсом |

## Установка

1. Откройте раздел [Releases](https://github.com/Hunter9568/Strazh-Releases/releases/latest).
2. В блоке **Assets** скачайте `Strazh-0.9.0-arm64.dmg`.
3. Откройте DMG и перенесите «Страж» в папку «Программы».
4. При первом запуске macOS может заблокировать приложение, поскольку текущая
   версия распространяется без платного Apple Developer ID.
5. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите
   «Всё равно открыть» рядом с сообщением о «Страже».
6. В профиле скопируйте запрос устройства и получите у продавца индивидуальный
   код активации.

Не отключайте Gatekeeper и не выполняйте команды `xattr`, найденные в интернете.

# Страж

Локальный голосовой AI-помощник для macOS, который умеет разговаривать,
управлять компьютером, выполнять пользовательские сценарии и работать с
локальными или облачными моделями.

> Официальный репозиторий установочных файлов. Исходный код, приватные ключи
> лицензирования и данные покупателей здесь не публикуются.

## Почему «Страж»

- **Голос без отправки записи в облако.** Распознавание речи Whisper и русская
  озвучка работают локально на Mac.
- **Локальный AI.** Поддерживаются локальные модели LiteRT и llama.cpp; для них
  текст диалога не требуется передавать внешнему провайдеру.
- **Выбор облачного AI.** При необходимости можно подключить OpenAI-совместимый
  API, OpenRouter, Anthropic, Ollama или собственный совместимый сервер.
- **Управление macOS голосом.** Запуск приложений и сайтов, поиск в интернете,
  ввод текста, громкость, музыка и таймеры.
- **Собственные команды.** Можно собрать сценарий из нескольких шагов, назначить
  ему голосовую фразу и варианты распознавания.
- **Визуальные сценарии.** Страж умеет ждать нужное приложение и взаимодействовать
  с заранее выбранными элементами интерфейса.
- **Безопасное выполнение.** Опасные или неизвестные действия не выполняются
  произвольно; чувствительные операции требуют явного подтверждения.
- **AI-чат с памятью и историей.** Есть отдельные чаты, вложения, проектный
  контекст и персонализация ответов.
- **Проекты и локальная библиотека.** Документы и веб-материалы можно объединять
  в рабочие проекты и использовать как контекст для диалога.
- **Telegram.** Подготовка сообщений с подтверждением пользователя и удалённые
  голосовые команды при включённой интеграции.
- **Персональный интерфейс.** Темы, фон, голос, образ помощника, экранный питомец,
  режим стримера и запуск вместе с macOS.
- **Защищённая лицензия.** Индивидуальный код привязывается к одному Mac; данные
  лицензии хранятся в системной Связке ключей и Secure Enclave, когда он доступен.
- **Подписанные обновления.** Приложение проверяет подлинность манифеста обновления
  до того, как предложить новую версию.

## Системные требования

| Компонент | Требование |
|---|---|
| Компьютер | Mac с Apple Silicon: M1, M2, M3, M4 и новее |
| macOS | 14 или новее |
| Место на диске | Не менее 2 ГБ; больше при установке локальных AI-моделей |
| Разрешения | Микрофон; Универсальный доступ — только для управления интерфейсом |

## Установка

1. Откройте раздел [Releases](https://github.com/Hunter9568/Strazh-Releases/releases/latest).
2. В блоке **Assets** скачайте `Strazh-0.9.0-arm64.dmg`.
3. Откройте DMG и перенесите «Страж» в папку «Программы».
4. При первом запуске macOS может заблокировать приложение, поскольку текущая
   версия распространяется без платного Apple Developer ID.
5. Откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите
   «Всё равно открыть» рядом с сообщением о «Страже».
6. В профиле скопируйте запрос устройства и получите у продавца индивидуальный
   код активации.

Не отключайте Gatekeeper и не выполняйте команды `xattr`, найденные в интернете.

# Страж 0.10.1

Исправление установки и распространения.

- в DMG отображаются только «Страж» и ярлык «Программы»;
- значки расположены для привычного перетаскивания приложения;
- документы и лишние папки удалены из образа;
- добавлен официальный Terminal-установщик;
- Terminal-установщик проверяет SHA-256 перед установкой;
- приложение устанавливается в `/Applications`;
- на рабочем столе автоматически создаётся ярлык «Страж»;
- после установки приложение автоматически запускается.

Для ручной установки скачайте `Strazh-0.10.1-arm64.dmg`, откройте его и
перетащите «Страж» на ярлык «Программы».

# Страж 0.10.0

Крупное функциональное обновление тестовой версии для Apple Silicon.

## Новые возможности

- мультимодальное зрение: анализ снимка с камеры по явной голосовой команде;
- передача изображений локальным vision-моделям, Claude и совместимым облачным API;
- чтение сегодняшних задач из macOS «Напоминания»;
- подготовка списка задач для Telegram с подтверждением отправки;
- актуальные каталоги моделей OpenRouter, NVIDIA NIM и Bytez;
- поиск и фильтр бесплатных облачных моделей;
- явные поисковые команды сразу открывают результаты в браузере;
- шесть вариантов естественных голосовых ответов без постоянных повторений;
- имя в голосовом подтверждении берётся из персональных настроек пользователя.

## Улучшения

- API-ключи продолжают храниться только в Keychain;
- каталог моделей кэшируется между запусками;
- обновлено описание системных разрешений камеры и Напоминаний;
- добавлены инструкции активации и восстановления доступа;
- опубликованы политика конфиденциальности и пользовательское соглашение.

## Установка

Скачайте `Strazh-0.10.0-arm64.dmg`, откройте образ и перенесите «Страж» в
«Программы». Эта тестовая сборка не подписана платным сертификатом Apple
Developer ID, поэтому при первом запуске может понадобиться кнопка
**Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

Требования: macOS 14 или новее, Mac с Apple Silicon.
